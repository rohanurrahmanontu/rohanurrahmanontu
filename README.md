## About

I design and build agentic AI systems that execute workflows autonomously, eliminate repetitive tasks, and run reliably 24/7.

AI Developer at **Digitalliyo** and AI automation instructor at **Green Spark Academy**, based in Kuala Lumpur. Since 2023 I've shipped 20+ automation systems for clients worldwide, from customer-support agents to reporting pipelines.

**Principles**
- Automate the boring — if a person repeats it every week, an agent should own it
- Reliable over clever — built to run unattended, with clear failure paths
- Data-informed — every workflow is measured, so results are visible, not assumed
- Teach what I build — clean handover and documentation so your team can own it
